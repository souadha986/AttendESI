# AttendESI 🎓

AttendESI is a Flutter project designed to make attendance management easier at ESI.

The project includes four applications for different users:

* **Prof:** For professors.
* **Étudiant:** For students.
* **Admin:** For administrators.
* **Scolarité:** For the school administration.

## 🛠️ Built With

* Flutter
* Dart
* REST APIs
* Firebase (where configured)

## 📂 Project Structure

Each application has its own folder and Flutter project.

## 🚀 Getting Started

1. Clone the repository.

2. Open the folder of the application you want to run.

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```

This project was developed as part of our work on making school attendance management simpler and more organized.
